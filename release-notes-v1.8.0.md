# solar-layout-card v1.8.0

## Added

- New "Show Watt value on panels" setting (`show_panel_reading`, on by default). Turn
  it off to leave just the panel's colour, without the Watt text over it — for a
  calmer, purely visual overview.
- New "Hide sleep icon" setting (`inv_hide_sleep`, off by default — icon shown). Lets
  you turn off the Zzz badge entirely if it gets cluttered with the display mode
  you're using (e.g. badge or text mode).

## Updating

Update via HACS and then do a hard browser refresh (or clear the `.gz` in
`www/community/solar-layout-card/`) if you don't see the change immediately.
