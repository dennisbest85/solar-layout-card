# solar-layout-card v1.10.1

## Fixed

- The "+ sensor" list (extra sensors) wasn't shown in the editor for "Merge with
  panel" mode, so — unlike "Extended data" — you couldn't add more than the main
  sensor.
- Merged values in the panel's reading pill ran together on one line; each value
  now gets its own line within the same bubble, matching "Extended data".

## Updating

Update via HACS and then do a hard browser refresh (or clear the `.gz` in
`www/community/solar-layout-card/`) if you don't see the change immediately.
