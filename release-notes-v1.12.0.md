# solar-layout-card v1.12.0

## Added

- A connection line can now be clicked directly on the canvas to remove it (with a
  hover highlight so it's clear the line is clickable), instead of only being
  removable via the separate "Connections" list below the canvas. That list is
  still there for adjusting colour/shape.

## Updating

Update via HACS and then do a hard browser refresh (or clear the `.gz` in
`www/community/solar-layout-card/`) if you don't see the change immediately.
